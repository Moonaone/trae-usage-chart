# Trae Usage Chart

离线、纯本地的 TRAE CN 用量统计扩展。记录每次 AI 会话消耗的 token、缓存与积分，并绘制成面板图表。
不上传、不联网、无遥测。

> **非官方扩展**，与 TRAE 官方无关。它通过 Chrome DevTools Protocol 读取 TRAE 自身的网络响应，
> 因此 TRAE 升级后可能失效。

完整说明、使用前置条件（**需要开启调试端口**）与构建方式见仓库根目录的 `README.md`。

## 命令

- `Trae Usage Chart: 打开用量面板`
- `Trae Usage Chart: 刷新`
- `Trae Usage Chart: 显示诊断`
